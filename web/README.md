# 诗行漫记

面向古诗词的知识地图站点，提供三条阅读路径：

- 行迹卷：按时间和地点阅读诗人的人生经历与作品。
- 诗境图：把诗句中的山河、城邑与题咏空间放回地图。
- 交游录：查看诗人之间可追溯的交游关系。

所有公开内容均来自站内已发布的数据投影，并保留来源与审核状态。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

## 校验

```bash
npm run lint
npm run build
npm test
```

`/agent` 提供一个本地私有的书籍分析工作台：支持文本书籍上传、候选抽取、证据/锚点预览、人工审核和发布清单导出。它是规则驱动的半成品，不会直接改写公共数据；文本层 PDF 仍请使用仓库根目录的 Python agent。
